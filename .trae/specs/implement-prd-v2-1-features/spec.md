# 个人工作台 PRD V2.1 全功能实现 Spec

## Why

当前 `workbench-desktop.html` 和 `workbench-mobile.html` 基于 personal-workbench 技能模板搭建，已完成基础框架（12 模块 CONFIG、通用 CRUD、侧栏/抽屉导航、鼠尾草绿主题、localStorage 持久化），但 PRD V2.1 要求的大量业务逻辑尚未实现：金币激励机制、五账户月额度、天气卡片、待办聚合、徽章系统、看板拖拽、手绘工具、数据导出、暗色模式、植物成长日记时间轴、目标里程碑、灵感阅读计时、花销分析图表、情侣日记天数计算、提醒日历、厨房助手四子功能等。本 spec 旨在补齐所有 PRD 功能缺口。

## 技术栈

- **现有**：自包含 HTML 文件，原生 HTML5 + CSS3 + JavaScript ES6+，localStorage 持久化，无构建步骤、无后端、无框架
- **保持**：继续使用单文件方案（desktop + mobile 两个文件），CONFIG 结构两端一致
- **新增**：PWA manifest + Service Worker（离线缓存）、Web Push API（提醒推送，MVP 阶段降级为站内通知）

## What Changes

### 核心基础设施
- 新增金币激励机制引擎：待办完成、每日学习、内容阅读、省钱、运动、目标里程碑、组合技七维度自动发币，周/日封顶
- 新增五账户体系：日常（月额度=当月天数×50，月初重置）、固定、收入、金币（1币=1元）、心愿，账户间严格独立
- 新增徽章系统：8 种徽章自动解锁判定 + 解锁弹窗特效
- 新增数据导出/导入：JSON 全量导出/导入、CSV 扁平化导出
- 新增暗色模式：日间/夜间/跟随系统三态切换，CSS 变量驱动
- 新增 PWA：manifest.json、Service Worker 离线缓存、安装引导

### 今日中枢（首页）
- 顶部问候区：时间感知问候语 + 连续打卡天数 + 天气入口（点击弹出天气详情卡片）
- 天气功能：API 获取（MVP 可手动录入），展示温度/湿度/AQI/紫外线 + 穿衣/出行建议，3 小时缓存
- 每日学习区：四项打卡（科技/理财/新闻/认知），点击即完成，每日 0:00 重置，可自定义增删改
- 待办速览区：从每日计划模块实时读取今日待办进度，点击跳转
- 五账户速览：从财富工坊实时读取五账户余额 + 今日开销 + 月额度进度条

### 每日计划/待办
- 全模块待办聚合：植物养护（到日期自动生成）、目标管理（每日学习计划）、项目看板（高优先级）、智能提醒（到期转待办）、手动添加
- 分类筛选标签：全部 / 各来源模块 / 自定义分类
- 优先级三级（高/中/低）、截止时间、超时标红
- 完成锁定机制、每日重置/延期、周回顾完成率
- 金币奖励：每日全完成 1 金币（周封顶 7）

### 健康生活
- 运动记录：自定义运动类型增删改（名称+图标+消耗系数），自动计算热量，周/月趋势
- 减脂追踪：体重+体脂率+目标体重，趋势折线图，热量缺口=消耗-摄入
- 厨房助手四子功能：食材管理（保质期追踪+分类+库存预警）、菜谱推荐（基于食材+缺失清单）、购物清单（从菜谱生成+手动添加+勾选已购）、营养追踪（热量汇总+三大营养素比例+趋势图）
- 运动消耗同步到减脂模块、摄入从厨房同步

### 植物养护
- 一级页面：植物卡片总览（名称+种植日期+成长天数+状态图标+养护倒计时+空状态引导）
- 二级页面：单株详情（照片九宫格+时间轴日记+成长分析情感文案）
- 7 种动态反馈图标（🌱发芽/🌿生长/🪷开花/🍂休眠/🪴茂盛/🍁落叶/🥀枯萎）
- 养护频率自动生成每日计划待办，落叶/枯萎触发急救养护待办
- 操作标签：换水/浇水/施肥/修剪/观察

### 目标管理
- 目标类型：学习/考证/阅读/自定义
- 里程碑拆分 + 完成状态标记
- 每日/每周学习时长目标 → 自动生成每日计划学习任务
- 考试倒计时（30 天内标橙）、模拟考成绩记录
- 进度条 + 完成百分比、金币奖励（里程碑 2 金币）
- 与工作笔记学习笔记打通

### 灵感补给站
- 子分类切换：每日知识/好书推荐/经典名句/电影推荐/知识解读/理财串珠
- 每日知识推送：每日 2 新 + 前日 2 条，右侧内容区展示完整文章
- 阅读计时：停留超 30s + 标记已读获 0.5 金币（日封顶 2、周封顶 14）
- 好词好句摘抄独立子页面：分类筛选（励志/哲思/爱情/古诗词/生活）+ 关键词搜索 + 导出 TXT

### 财富工坊
- 快速记账：分类按钮 + 金额 + 备注 + 照片，仅从日常账户扣减
- Tab 切换：花销分析（周/月趋势折线图 + 月度结构饼图）/ 收入管理 / 固定支出 / 购买清单 / 心愿兑换 / 实时金价
- 月额度=当月天数×50，耗尽当月停用日常账户
- 心愿兑换：金币账户扣金币 → 心愿账户加余额
- 省钱奖励阶梯制（1-15元→2币、16-30元→1币、31+→0币）

### 时光胶囊
- 情侣日志：顶部"在一起 XXX 天"+ 下一个纪念日倒计时，开始时间可改，5 种心情筛选，日历视图 ❤️ 标记，回忆精选 🌟 珍藏，红粉色调
- 备忘录：4 分类（学习/生活/灵感/其他）+ 富文本 + 照片 + 手绘插入 + 标签 + 置顶 + 搜索 + 导出
- 手绘工具：半屏画板，12 色 + 吸管 + 4 种画笔 + 3 档粗细 + 图形/文字工具 + 10 步撤销 + 3 种背景 + 导出 PNG

### 智能提醒中心

- 提醒类型：生日（农历/公历，每年重复，提前 N 天）、定期联系（每周/月）、自定义（一次性/每日/每周/每月/每年）

- 徽章墙：8 种徽章（连续全勤/阅读达人/省钱小能手/植物达人/记忆收藏家/运动健将/目标达成者/知识海绵），解锁弹窗特效

- 周报卡片：每周日自动生成（金币总数+最高单项+连续天数+雷达图），一键保存/分享

- **Affected files**: `workbench-desktop.html`、`workbench-mobile.html`（两端 CONFIG 与 :root 保持同步）

## ADDED Requirements

### Requirement: 金币激励机制引擎
系统 SHALL 提供全局金币引擎，监听七维度行为自动发币：
- 待办全完成 → 1 币/日（周封顶 7）
- 内容阅读停留 30s+标记已读 → 0.5 币/篇（日封顶 2，周封顶 14）
- 每日学习四项全完成 → 0.5 币/日（周封顶 3.5）
- 省钱阶梯（1-15→2币、16-30→1币、31+→0币，周封顶 14）
- 运动记录 → 0.5 币/次（日封顶 1，周封顶 7）
- 目标里程碑完成 → 2 币/个（无封顶）
- 组合技（晨间/阅读/记录/运动套餐）→ 额外 0.5-1 币/日
- 金币满 10/20/50/100 弹窗庆祝

#### Scenario: 待办全完成发币
- **WHEN** 用户完成今日全部待办
- **THEN** 金币账户 +1，记录金币明细来源"待办"，检查组合技

#### Scenario: 省钱阶梯发币
- **WHEN** 当日可变支出（日常账户）合计 ≤ 15 元
- **THEN** 金币账户 +2，来源"省钱"

### Requirement: 五账户体系
系统 SHALL 维护五个严格独立的账户：
- 日常账户：月额度=当月天数×50，月初重置，耗尽当月停用，仅用于可变支出
- 固定支出账户：预设项目自动扣减，不占日常额度
- 收入账户：手动记录，独立统计
- 金币账户：1 币=1 元，仅用于心愿兑换
- 心愿账户：金币兑换后转入，不占月额度

#### Scenario: 日常账户月额度耗尽
- **WHEN** 当月日常账户余额 ≤ 0 且用户尝试可变支出记账
- **THEN** 阻止记账并提示"本月日常额度已耗尽"

### Requirement: 天气功能
今日中枢 SHALL 提供天气入口，点击弹出详情卡片，展示温度/湿度/AQI/紫外线 + 穿衣/出行建议。MVP 阶段支持手动录入，数据 3 小时缓存。

#### Scenario: 点击天气入口
- **WHEN** 用户点击天气入口
- **THEN** 弹出天气详情卡片，展示缓存数据或提示手动录入

### Requirement: 待办聚合
系统 SHALL 自动从其他模块生成每日待办：
- 植物养护：到达养护日期 → "🌱 [植物名]换水/浇水" 待办
- 目标管理：每日学习计划 → "🎯 [目标名]学习" 待办
- 项目看板：高优先级任务 → "📊 [任务名]" 待办
- 智能提醒：到期提醒 → "⏰ [提醒标题]" 待办
- 手动添加：用户直接添加 → "📝 [内容]" 待办

#### Scenario: 植物到养护日期
- **WHEN** 某植物距上次养护达养护频率天数
- **THEN** 每日计划自动生成对应养护待办，前缀 🌱

### Requirement: 徽章系统
系统 SHALL 自动判定 8 种徽章解锁：
- 🔥 连续全勤（连续 7 天待办全完成）
- 📚 阅读达人（累计已读 50 篇）
- 💰 省钱小能手（连续 7 天日开销 ≤ 15 元）
- 🌱 植物达人（养护记录 ≥ 30 天）
- 💕 记忆收藏家（情侣日志 ≥ 100 篇）
- 💪 运动健将（累计运动 50 小时）
- 🎯 目标达成者（完成 3 个目标）
- 🧠 知识海绵（每日知识阅读满 100 条）

#### Scenario: 解锁徽章
- **WHEN** 用户行为满足某徽章条件且此前未解锁
- **THEN** 弹窗庆祝展示徽章图标+名称，记录解锁时间

### Requirement: 数据导出导入
设置页 SHALL 提供 JSON 全量导出/导入和 CSV 扁平化导出。

#### Scenario: 导出 JSON
- **WHEN** 用户点击"导出 JSON"
- **THEN** 下载包含所有 localStorage 数据的 JSON 文件

### Requirement: 暗色模式
系统 SHALL 支持日间/夜间/跟随系统三态，通过 CSS 变量切换。

#### Scenario: 切换夜间模式
- **WHEN** 用户选择"夜间"
- **THEN** :root 切换为深森林墨绿色板，保存偏好到 localStorage

### Requirement: 看板拖拽
项目看板 SHALL 支持任务卡片拖拽跨列移动。

#### Scenario: 拖拽任务
- **WHEN** 用户拖拽任务卡片到另一列
- **THEN** 更新任务列状态，刷新看板

### Requirement: 手绘工具
时光胶囊 SHALL 提供半屏画板，支持 12 色、吸管、4 种画笔、3 档粗细、图形/文字工具、10 步撤销、3 种背景、导出 PNG，可在备忘录和情侣日志中调用。

### Requirement: 植物成长日记
植物详情页 SHALL 展示照片九宫格 + 时间轴日记（日期倒序）+ 成长分析情感文案，7 种动态反馈图标。

### Requirement: 目标里程碑
目标管理 SHALL 支持里程碑拆分、每日/每周学习时长目标、考试倒计时、模拟考成绩记录。

### Requirement: 灵感阅读计时
灵感补给站 SHALL 在内容展示时计时，停留超 30s + 标记已读获 0.5 金币，提供好词好句摘抄独立子页面 + 导出 TXT。

### Requirement: 花销分析图表
财富工坊 SHALL 提供周/月支出趋势折线图 + 月度支出结构饼图。

### Requirement: 情侣日记天数计算
时光胶囊 SHALL 自动计算"在一起 XXX 天"和"距下一个纪念日 XX 天"，开始时间可改自动重算。

### Requirement: 提醒日历视图
智能提醒中心 SHALL 提供月历视图，有提醒的日期标记，点击查看当日列表。

### Requirement: 厨房助手四子功能
健康生活 SHALL 包含食材管理（保质期追踪+分类+库存预警）、菜谱推荐（基于食材+缺失清单）、购物清单（从菜谱生成+勾选已购）、营养追踪（热量+三大营养素+趋势图）四子功能闭环。

### Requirement: PWA 支持
系统 SHALL 提供 manifest.json + Service Worker 实现离线缓存和安装到主屏幕。

### Requirement: 设置页功能化
设置模块 SHALL 从纯文本卡片升级为功能化页面：账户、数据导出导入、外观切换、通知开关、关于信息。
